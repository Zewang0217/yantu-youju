# 研途有据 —— 面向推免择校的可信决策 AI Agent

> 推免个性化推荐系统 · 华为 ICT 创新赛参赛项目设计仓库

面向有推免择校需求的学生,提供基于个人情况的院校与专业推荐:看懂申请条件、发现适合的机会、理解选择依据。产品由两条协作的 Agent 生产线组成:

1. **资料生产线**:自动发现、获取、整理各院校推免政策资料,每条信息附来源 URL,经复核后结构化留存,并积累可跨年度复用的院校入口库;
2. **咨询服务线**:通过对话构建用户画像,筛选候选并实时复核最新政策,输出带理由、带官方来源与待确认点的个性化推荐。

当前处于**设计阶段**(构想 → 调研 → PRD → 需求分析 → 架构 → 详细设计 → 评审 → 开发),尚无代码。阶段进度与待办见 [TODO.md](TODO.md)。

## 文档状态约定

本仓库文档多由 AI 助手(Codex / ZCode)依据用户输入起草,文件头 `status` 标注其状态:**草稿待审阅**的文档不构成团队正式决定;**已采纳**需用户明确确认后记录范围与日期。详见[文档处理规则](文档处理规则.md)。

## 协作约定

- 设计讨论以 PRD 与各阶段设计文档为准;修改文档时同步更新文件头 `updated` 与 `status`。
- 未决问题集中在 [TODO.md](TODO.md) 跟踪,解决后勾选并注明结论与日期。
- 图(PUML 源文件 + 导出的 SVG/PNG)放在所属文档同目录的 `PlantUML/` 子目录。
- 含个人信息的原始材料(会议纪要、申报表等)仅保存在本地,不入库。
