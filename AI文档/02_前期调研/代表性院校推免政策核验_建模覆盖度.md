# 代表性院校推免政策核验:领域建模覆盖度

作者:ZCode(AI助手),调研由 5 个并行子代理执行。日期:2026-10-23。目的:用真实推免政策反向核验《领域与信息模型》v0.1 的覆盖度,并识别院校扩展时将引入的新判断条件与结构差异。样本为 5 类结构性差异明显的代表:**清华**(顶级综合)、**上交**(超大院系重组)、**南大**(同学科多学院)、**南方科技大学/上科大**(新型高校)、**中科院计算所**(科研院所)。数据主年度为 2027 级(2026 年发布);各校详细原文与完整 URL 见各代理报告结论(本稿为浓缩版,保留关键 URL)。

## 1. 结论先行

1. **核心概念方向正确,但"招生机会"的定位粒度不足**:五校一致证明,机会不是"院系×专业×年度×批次"四元组,而是**培养单位×专业(×研究方向)×年度×批次(项目化)×学位类型×专项轨道×考生身份范围**的多轴组合;同一批次下不同轴的组合条件、考核、是否限本校完全不同。
2. **条件类型的真实谱系远超"硬门槛+放宽条款"二分**:定性条款、裁量性放宽、负向条件、事后生效条件、义务型条款、身份型条件、跨专业三种认定范式、英语互替+版本排除——都是真实存在且各校不同的类型。
3. **可扩展性的正确解法不是穷举条件,而是"开闭的条件框架 + 未知条款降级"**:新院校必然带来清单外条款;模型必须保证**未结构化条款不破坏判断可信性**(降级为"无法判断+原文展示+待确认点"),这与 PRD 既定原则天然一致。
4. 组织结构(院系层)、批次命名、状态生命周期、信息载体均存在系统性差异,详见 §4 缺口清单与《领域与信息模型》v0.2 的扩展性设计。

## 5. 对建模的启示(已落实到 v0.2)

1. **开闭原则落地为三层**:①核心身份概念稳定(培养单位/招生机会/规则/证据/版本);②枚举与轴开放(条件类型注册、批次项目化、专项轨道);③未知条款统一降级路径(未结构化→无法判断→原文展示→待确认点),保证新院校接入不破坏既有判断。
2. **证据模型必须比"URL"更强**:正文快照/附件内容/落款与发布双时间/同URL版本更新——否则清华式"PDF正文+动态页"与南大式"通知下架"直接破坏可追溯性。
3. **状态机从"报名状态三态"升级为"机会阶段"**,且时间需带置信度与权威源覆盖(以系统为准)。
4. **导师是领域一级概念**(意向填报/同意/联培归属),但"按导师推荐"仍属 PRD 后续版本,两者边界在模型中分开。
