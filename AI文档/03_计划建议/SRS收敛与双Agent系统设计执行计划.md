# SRS收敛与双Agent系统设计执行计划

作者：Codex（AI助手）。日期：2026-10-29。本文件记录本轮需求收敛、研究、设计和独立评审的顺序，供团队检查交付；详细业务规则只在SRS维护。

## 1. 授权与边界

用户已要求按现有流程继续，review由subagent完成，先多轮收敛SRS，再完成含eval、日志错误、工作流状态的双Agent系统设计。本轮是一个设计工作单，研究可分工并行，SRS与架构分阶段收敛；不并行实现多个功能。此前PRD v0.7的新增产品建议不自动采纳。

已读取全局唯一真源：WSL Ubuntu-20.04 `/home/zewang/.agents/AGENTS.md`及适用引用。服务器/依赖/镜像/CI/密钥操作由用户执行，本轮不部署、不安装、不运行付费模型评测，不自动提交或push。新增资料全部在ICT项目树内。

## 3. 研究要回答的问题

资料线：如何先发现尽量完整的目标资料、复用入口、适应不同载体与政策类型；怎样识别来源依赖、政策冲突和新旧适用；如何用独立金标量准确率、范围内覆盖和时效，并与普通采集流水线比较。

咨询线：教育与生涯决策研究怎样帮助澄清目标和解释选择；哪些理论不能直接迁移到国内推免；在硬门槛独立的前提下，透明加权、多属性和语义方案如何公平比较；如何评价用户决策，而非把满意度或老师评分称作录取真值。

## 4. 评审职责

独立审阅者报告缺陷及位置，不替用户确认范围。主代理根据证据修订，保留R1/R2/R3及后续设计审阅记录。没有发现阻塞只代表本轮审阅结论；团队仍可修改设计，平台与算法仍需实际验证。
