## 复现

在仓库根目录设置`PYTHONPATH=src`、`TMP/TEMP=var/test_tmp`后执行：

```powershell
python -m unittest discover -s tests
python scripts/collect_ecnu_documents.py
```

用上一条命令返回的目录执行`python scripts/inspect_registration_windows.py <运行目录>/bundle.json`可产生各文档时间字段报告。1C1最终207测试通过；原21例发布安全回归仍21/21通过，报告`var/policy_eval/20261105-230149-d4cce630/`。可信演示`var/trusted_demo/b75e5c50198c4c2bafa1340da04a09c2/demo_report.json`保持真实条件unknown/窗口closed、不推荐，6条原文证据均验证通过。

运行输出新的requestId目录。`--live`才联网，受HTTPS主机白名单及拒绝重定向策略约束；没有模型调用。PDF依赖pypdf可选组，未安装时返回unsupported，不自动安装。时间预算为协作式检查和网络超时，PDF解析进程硬隔离尚未实现。
