# 任务发布与模型计量：2B

## 范围

SQLite 任务发布仓储与文件版发布库彼此独立，不迁移原有数据或切换现有读者。单步骤入口冻结快照身份、范围和预期版本，使用原单页独立核验门禁与离线保守提取器；事实版本、当前指针、审计、步骤状态和用量在同一事务提交。隔离结果不更新当前指针。正式发布能力仅限此入口和单机 SQLite，尚不代表完整资料生产线已经自动发布。

模型客户端保留原有文本接口，并提供显式的供应商 token 结果。成本缺少可信来源或供应商用量不完整时，保留已知分项，任务用量为待对账，不能按零费用结算。一次性模型任务入口显式注入客户端和传输，预留本地工具、token 和成本额度；不自动读取密钥或联网。发送后中断或失败不会自动重发，预算继续占用。预留是本地估算，不是供应商的硬限额，实际账单可能超出预留；价格与最终费用仍需可信来源。

## HLD

事务内共用任务完成逻辑，避免发布状态与任务产物、预算结算分两次提交。发布沿用 `TrustedPolicyPipeline` 的证据与语义门禁；发布仓储只承担存储和提交边界，不引入另一套核验规则。模型响应值与账本计量通过明确适配器转换，避免把未知成本伪装成零。可重放只读处理器与单次模型调用采用显式执行策略；不把模型 POST 注册成普通可重放步骤。

## 验证与限制

最终全量 unittest 413 项通过，日志 `var/test_tmp/2b-final-full.txt`；21 例既有离线政策回归通过。两路独立复核覆盖并发 CAS、审计故障回滚、旧租约、取消、截止、提交前后恢复、普通 runner 越权、模型派发后崩溃不重发、成本单位与可变输入；复核发现的单位校验、输入快照和 token 一致性问题已修复并补充测试，未发现剩余可复现 P1/P2。全部模型传输均为模拟，未调用实际供应商。

输入承诺不保存提示词或凭据，模型输出原文仍保存为任务产物，可能包含敏感内容，使用方必须依照数据存储规则处理。派发后取消可能无法撤销尚未完成的远端请求；租约只阻止失权结果落库。已知 token 超过预留而成本未知时，产物保留 token，账本暂按预留持有，超额需对账后确认。429 的 Retry-After 可由客户端读取，一次性任务目前不自动重试，也不把该值保存进任务事件。

本记录完成时旧文件库迁移和子任务配额尚未实现；后续已提供[显式迁移与只读接线](发布库迁移与只读接线_2026-11-06.md)和[单层子任务配额](单层子任务配额_2026-11-06.md)。真实供应商和账单实测、真实模型质量与多机调度仍未完成；默认资料任务及原有文件库的发布链路没有自动切换。
