# 单层子任务配额

本次仅实现单机同一 run 的根任务和一层显式子任务；不支持孙任务。`submit_child` 需要有效父租约，在同一 SQLite 写事务中冻结输入、步骤、单位和额度，核对运行预算并创建子任务。原有 `submit(parent_task_id=...)` 保持独立 run 的重跑关联，不自动变成共享预算。

父运行可用额度扣除已结算、在途/待对账预留及活跃子任务尚未花费的授权；子任务每次调用还须满足自身 grant。子任务结束后释放未使用的授权，已发送但未知用量仍占用预留。真实结算超过预留时按实际值记账，并阻止后续超额分配或调用；这不是供应商侧硬限额。

父任务执行完自身步骤但子任务未终结时进入 `waiting_input`，`inspect` 返回 `waitReason=children_pending` 和待结束数；最后子任务结束后汇总 completed/partial。父取消、失败或共同绝对截止会在事务中撤销子任务提交权。父 worker 的租约自然过期或换主不会自动取消已经下发的子任务；父新建子任务仍须持有有效租约。子任务继承运行截止时间，不设置独立子截止。

终态不因后续对账改写；若已结束子任务对账后超出自己的 grant，子 `childQuota.overrun` 与父 `budget.childOverruns` 显示该事实，即使运行总额尚未超出。未知成本不会按零结算。旧根任务已有未标单位的非零成本时不得下发配额；子任务对账需匹配冻结单位。调用方仍须保证实际工具账单及其单位来源可信，账本不自行校验供应商账单。

## HLD 与验证

预算授权与调用账本共用 SQLite 事务，避免把额度转移拆进无法原子提交的服务。独立子授权表保留新语义，避免改变旧重跑关联。子任务粒度与状态汇总在现有任务仓储内扩展，不引入通用工作流 DSL 或状态类族。

最终全量 449 项及 21 例离线政策回归通过，日志 `var/test_tmp/2c-quota-full.txt`、`var/test_tmp/2c-quota-eval.txt`；独立全量复核也为 449 项通过。17 项定向测试覆盖并发下发、父子等待/取消/截止、未知用量及单位、终态后的超额对账、真实子进程 dispatch 后崩溃恢复和旧 v1 库加表。独立 20 路并发探针中预算仅允许 5 个授权，实际恰好 5 个成功。审查发现的截止状态回滚、无单位成本混算、终态后子额度超额不可见均已修复。

本接口尚未接入默认资料任务或真实模型调用，层级更深的配额、多机调度和远端硬限额仍未实现。
